# API de Exercicio Git

API simples criada com Python e Flask para praticar
Git, GitHub, branches, commits e Pull Requests.

## Instalacao

pip install -r requirements.txt

## Executar

python3 app.py

## Endpoints

GET /health
Retorna o status da API.

GET /version
Retorna a versao atual da API.

Versao inicial: 1.0.0
